Native **200% browser zoom also passed**, using bundled Chromium **153.0.8010.12** in headless full-browser mode. A local test extension calls `chrome.tabs.setZoom(2)` with `mode: 'automatic'` and `scope: 'per-tab'`, then reads back `getZoom() === 2`. Automatic mode delegates zoom to the browser. This is the browser's page zoom, not CSS `zoom`, a smaller emulated viewport or a pinch-zoom transform. The method follows the [Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-setZoom), its [automatic zoom contract](https://developer.chrome.com/docs/extensions/reference/api/tabs#type-ZoomSettingsMode), and [Playwright's bundled-Chromium extension setup](https://playwright.dev/docs/chrome-extensions).
