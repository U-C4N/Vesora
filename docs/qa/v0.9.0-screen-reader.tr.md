# PRISM ekran okuyucu kontrolü

**Durum: pending — gerçek ekran okuyucu ile henüz uygulanmadı.** Bu form mevcut erişilebilirlik yayın kapısına aittir. Beş kişilik pilotun **en az 4/5 yardımsız yüzey → kesit → dondurma → dışa aktarma** ölçütüne ek görev veya başarı eşiği getirmez.

## Kurulum ve kayıt

Windows'ta Narrator veya NVDA'dan birini açın. Ürünün gerçek sürümünü kendi Hakkında/Ayarlar ekranından kaydedin; ikisini aynı anda çalıştırmayın. Fare kullanıldıysa adımını belirtin.

| Alan | Gerçek değer |
| --- | --- |
| Tarih / denetçi | — |
| Narrator veya NVDA / tam sürüm / konuşma dili | — |
| Windows / tarayıcı ve tam sürüm | — |
| RC / commit / manifest ve kurulu arşiv SHA-256 | — |
| URL veya notebook / kaynak checkout mu, kurulu arşiv mi? | — |
| Ekran okuyucu okuma/odak modu / zoom / tema | — |
| Konuşma günlüğü veya izinli kayıt yolu | — |

Son doğrulanmış adayın hostunu kullanın. Kaynak checkout üzerinde hazırlık için `npm run build` ve `npm run demo` çalıştırıp `http://127.0.0.1:4173/examples/web/v09.html` adresini açın. Canlı örnek için `npm run demo:react` komutunun verdiği URL'ye `?demo=workbench` ekleyin. Kaynak kontrolünü kurulu arşiv sonucu diye kaydetmeyin.

Aynı sayfadaki iki bağımsız görüntüleyici için hazırlayıcı, yerel sunucuda `/tests/browser/harness.html` sayfasını açıp bu kodu konsolda bir kez çalıştırabilir. Ardından konsolu kapatıp odağı sayfaya getirin. Bu hazırlık sesli kontrolün yerine geçmez.

```js
const {figure} = await import('/packages/core/dist/index.js');
const {mountViewer} = await import('/packages/core/dist/viewer.js');
document.querySelector('#chart').style.width = '100%';
for (const name of ['Bağımsız A', 'Bağımsız B']) {
  const host = document.createElement('div');
  host.style.marginBottom = '16px';
  document.querySelector('#chart').append(host);
  const fig = figure({title: name, height: 240});
  const line = fig.plot([], [], {label: name}).enableStreaming({maxPoints: 200});
  fig.setHoverMode('x');
  mountViewer(fig, host);
  let sample = 0;
  setInterval(() => {
    const x = sample++;
    line.appendData({x: [x], y: [Math.sin(x / 10)]}, {waitFor: 'accepted'});
  }, 100);
}
```

## Kontrol adımları

Her satıra `passed`, `failed` veya `not run` yazın. Beklenen anlam duyulmalıdır; ekran okuyucunun rol sözcükleri dil/sürüme göre değişebilir. Duyulmayan veya yanlış duyulan metni aynen kaydedin.

| Adım | Eylem ve beklenen davranış | Sonuç / duyulan metin / kanıt |
| --- | --- | --- |
| 1. Yapı | Başlık/bölge gezinmesiyle figür adını bulun. `Figure actions`, `Figure inspector` ve `Plot controls` ayırt edilebilmeli; gezinme figürde kilitlenmemeli. | not run — |
| 2. Odak | Tab/Shift+Tab ile `Reset view`, `Freeze view`, tema ve PNG/HTML düğmelerini gezin. Ad, rol ve odak duyulmalı; Enter/Space çalışmalıdır. | not run — |
| 3. Bölümler | `Layers`, `Inspector`, `Diagnostics` bölümlerini açıp kapatın. Açık/kapalı durum ve katman düğmesinin adı/basılı durumu anlaşılmalıdır. Inspector başlangıçta kapalıdır. | not run — |
| 4. 3D/kesit | Bilimsel örnekte Inspector'ı açın. `3D panel`, kamera düğmeleri, `Equal axes`, `Fit data` ve kesit sürgüsüne erişin. Sürgü adı/değeri duyulmalı, ok tuşlarıyla değişmelidir. Seçim yokken `Focus selection` hatası erişilebilir uyarı olarak okunmalıdır. | not run — |
| 5. Dondurma | Canlı örnekte `Freeze view` düğmesini Enter ile çalıştırın. Odak `Return to live` düğmesine geçmeli; `Frozen snapshot` ve varsa saat duyulmalıdır. Katman/tema düğmelerinin devre dışı durumu anlaşılmalıdır. | not run — |
| 6. Devam | `Return to live` sonrasında odak `Freeze view` üzerine gelmeli ve `Live` duyulmalıdır. Her yeni kare gereksiz durum anonsu üretmemelidir. Görüntünün dondurulması ile üreticinin durmasının farkının anlaşılıp anlaşılmadığını kaydedin. | not run — |
| 7. Bağımsızlık | Aynı sayfadaki A ve B'yi adlarından ayırt edin. A'yı dondurun; B canlı kalmalıdır. A'nın eylemi B'nin odağını, durumunu veya temasını değiştirmemelidir. | not run — |
| 8. Gözlem | Hazırlayıcı yüzeyde bir gözlem seçsin. Inspector açılmalı; seçili/interpolasyon açıklaması, hücre/üçgen, koordinatlar ve kaynak bilgisi okunabilmelidir. Hazırlıkta fare kullanımı, klavyeyle nokta seçimi başarısı değildir. | not run — |
| 9. Dışa aktarma | Dondurulmuş görünümün PNG/HTML düğmelerini klavyeyle çalıştırın. İndirme bildirimi/dosya erişilebilir olmalı; odak kaybolmamalıdır. HTML'yi çevrimdışı açın: figür ve mevcut seçili gözlem okunmalı; canlı üretici veya `Freeze view` beklenmemeli, `Download PNG` erişilebilir olmalıdır. PNG etkileşimli veri/metin alternatifi sağlamaz. | not run — |
