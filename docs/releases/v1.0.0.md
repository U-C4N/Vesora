# Vesora 1.0.0 local source release

Core, React and Python source identities are 1.0.0. This documents implementation and review assets, not registry publication.

Added families: ECDF/CCDF, supplied spectrogram with bounded rows, event timeline, asymmetric error bars, contour/filled contour, quiver, parallel coordinates, Pareto, phase portrait/hysteresis and ternary. Protocol 9 preserves their source values/options; protocols 1–8 remain readable.

The portable `skills/vesora` skill includes host references and runnable three-language examples. `llms.txt` is the compact LLM documentation entry point.

`npm run verify:next` supplies one maximum-ten-minute automatic check including build, archives, real browser/offline and installed-wheel Qt/Jupyter workflows. Success needs an actual report under `artifacts/v1-verification`; incomplete runs fail. Historical endurance/human evidence is neither changed nor inferred.

`npm run package:release -- --candidate` writes `dist/release-v1.0.0`. Local candidate files cannot be published by the existing guarded publisher. The verifier does not create tags, commits, uploads or publication claims.

See the [API guide](../v1.md) and [verification contract](../verification-v1.md).
