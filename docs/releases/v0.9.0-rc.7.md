# Vesora 0.9.0-rc.7 — Observations, faster startup and Denge

> **Superseded review candidate:** RC7 stays a draft. Its installed React 19 Vite checks passed, but the Next 16.4.0 consumer build stopped on a verified security advisory. [RC8](v0.9.0-rc.8.md) updates the development-only Next dependency to 16.4.2 and has a fresh archive identity. RC7 artifacts and evidence remain unchanged.

**Release candidate for review.** RC7 has a new package identity: JavaScript `0.9.0-rc.7`, Python `0.9.0rc7`, tag `v0.9.0-rc.7`. It is prepared as a GitHub draft; npm and PyPI publication are not part of this delivery. It is not an accepted stable release. The fixed RC6 archives, tag and historical evidence remain unchanged.

## What changes

- **One observation model.** JavaScript and Python can declare channel units, quantities, origins and external transform metadata. Opt-in HTML observations distinguish accepted data from the displayed frame, including frozen source ownership and stream intervals. Declarations use scene protocol 8; protocols 1–7 still import. Metadata describes values; it does not execute transforms or convert units.
- **Studio and Embed.** One viewer supports both workspaces, scoped theme tokens and explicit controls. Switching modes preserves the mounted figure and frozen observation. React exposes the same options through `VesoraViewer`.
- **Smaller startup imports.** `@vesora/core/runtime` keeps the HTML template outside the initial dependency graph. Async HTML export captures source ownership before loading its template. React demos load by route; the viewer does not need the SaaS dashboard styles to start.
- **Focused performance improvements.** Repeated narrow scatter queries can reuse a bounded exact index. HTML encoding uses bulk byte copies while retaining the original binary representation. Cold queries and unsupported inputs retain the scan path.
- **Denge Membrane.** An experimental React demo expresses a connected pair as two regions in a fixed area. Their curved boundary preserves the exact volume ratio; the hatched area represents the amount needed to reach equal shares. It uses the conservative `@vesora/core/balance` model and a linked 3D observation. The interface now uses the existing Vesora logo.

The Membrane renderer lives in the React example; it is not a new public `@vesora/react` export. The curve is a visual encoding, not a fluid-surface simulation. No world-first, patent novelty or newly discovered physical law is claimed. Denge HTML export contains the displayed 3D scene and observation, not the 2D controller or a resumable simulation.

## Try the candidate

From this tag's source checkout:

```sh
npm ci
npm run build
npm run demo:react
```

Open the Vite URL with `?demo=workbench` for Studio/Embed or `?demo=balance` for Denge. Node.js 22.12+ and a WebGL2-capable browser are required for development and viewing.

Install the fixed candidate assets from the draft into a separate project or environment:

```sh
npm install ./vesora-core-0.9.0-rc.7.tgz ./vesora-react-0.9.0-rc.7.tgz
python -m pip install ./vesora-0.9.0rc7-py3-none-any.whl
```

Python requires 3.10+. The release directory also contains ten self-contained HTML demos, a source/runtime manifest and SHA-256 checksums. The React application is available in the tagged source checkout; the ten standalone demos do not include its Membrane controls.

## Validation and remaining acceptance

Source preflight passed TypeScript checking, 415 core tests, 41 React tests, 442 Python tests and 65 release-contract tests. The Python run skipped 15 host-dependent tests; those skips do not establish Qt/Jupyter acceptance. Focused browser checks cover Membrane area ratios in both transfer directions, 320/390 px layouts, keyboard interaction, conservation and displayed 3D export.

These development checks are not substitutes for the final archives' acceptance reports. Each new archive starts with its own pending gate inventory. Exact-file verification, installed-package checks and their raw reports are retained with the candidate when run. See `release-gates.json` and `evidence/` for the authoritative archive-bound status.

The full same-archive gate set remains required before publication: correctness, browsers, Qt, Jupyter, React consumers, packages, performance, endurance, accessibility and the five-person pilot. The real screen-reader/pilot sessions have not been conducted. The earlier RC6 endurance run failed after Windows standby; it does not pass RC7's endurance requirement. Long runs are not being restarted as part of this short release preparation.

The [startup measurements](../benchmarks/v0.9.0.md#development-startup-and-bundle-comparison-2026-10-23) refer to the recorded development builds and local paired workload, not the RC7 archive or a universal performance guarantee.
