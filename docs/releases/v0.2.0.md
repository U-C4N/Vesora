# Vesora v0.2.0 — Share Interactive Discoveries

Create a scientific figure in Python or JavaScript, save the viewpoints that explain your findings, and share it as one interactive HTML file. The recipient can open it directly from disk and explore it without Python, a local server, or an internet connection.

**Developer preview.** The API continues to evolve. Interactive viewing requires WebGL2. HTML files contain the original exported source data; Python callbacks, application code, parameter sliders, and live connections are not included.

## Share a discovery

```python
import vesora as vs

fig = vs.figure(title="Measurements")
fig.scatter([1, 2, 3], [2, 4, 3], label="Samples")
fig.bookmark("Overview")
fig.set_axes(xlim=(1.5, 2.5), ylim=(3.5, 4.5))
fig.bookmark("Detail", note="Inspect the highest measurement.")
fig.restore_bookmark("Overview")
fig.save_html("measurements.html")
```

In JavaScript, the equivalent export is `toHTML(fig)` for an HTML string or `downloadHTML(fig, "measurements.html")` for a browser download. Both languages can generate HTML before displaying a figure.

## Included in this release

- Self-contained HTML with the shared engine, worker, typed source data, and offline viewer.
- Named bookmarks with plain-text notes, stable replacement order, and complete view restoration, including automatic axis limits and 3D pan.
- An English viewer with bookmarks, reset, PNG download, and a per-layer representation inspector. Density counts are explained separately from individually drawn points.
- HTML downloads throughout the 16-example gallery. The million-sample density example includes `Overview`, `Separate clusters`, and `Individual samples` bookmarks.
- Corrected view-state synchronization across reset and bookmark restoration. Existing PNG export and the five plot types remain available.

Bookmarks describe viewpoints of one current dataset. They do not store historical data, styles, layer visibility, or selections. The file opens at the export-time view; reset returns to that view rather than to its first bookmark.

## Download and install

Download the packages from the [v0.2.0 GitHub Release](https://github.com/U-C4N/Vesora/releases/tag/v0.2.0). Python 3.10+:

```bash
python -m pip install ./vesora-0.2.0-py3-none-any.whl
```

For a JavaScript/TypeScript frontend:

```bash
npm install ./vesora-core-0.2.0.tgz
```

The Python wheel includes the engine. HTML generation does not initialize Qt, although the normal Python installation still includes the desktop dependencies. The npm package has no runtime dependencies. These packages are distributed through GitHub; this release does not publish to the npm or PyPI registries.

The release also includes `vesora-discovery-demo.html`, a standalone synthetic-data example, and `SHA256SUMS.txt` covering the downloadable packages and demo.

## Validation and compatibility

The release validation covers unit and Python tests, Python/JavaScript scene parity, gallery snippets, browser rendering, direct offline HTML opening, bookmark navigation, 3D pan, PNG export, script-safe text, and a 320px viewer layout. Distribution checks install the wheel and tarball in separate clean environments outside the checkout and open the HTML they produce.

Scene protocol version `1` is retained. New optional bookmark and pan fields do not prevent the new engine from reading older snapshots. HTML has its own format version and embeds its matching engine; older engines are not expected to implement new bookmark or pan behavior.

There are no new plot types, linked multi-view layouts, live streaming providers, SVG/PDF output, or WebGPU renderer in this release. Large datasets increase file size because full source arrays are included. Synthetic examples and software-rendered browser tests do not establish a hardware performance guarantee.
