# Vesora v0.4.0 — Statistics and categories

Compare distributions and named groups without switching plotting libraries. Python and JavaScript expose histogram, bar, horizontal bar and boxplot layers backed by the same TypeScript preparation and rendering engine. Source arrays remain available in exported, offline HTML.

**Local developer preview.** The packages described here are built from the working checkout, including the existing v0.3 work. Packaging does not publish to GitHub, PyPI or npm. WebGL2 remains required; NumPy remains optional.

## Create a statistical comparison

```python
import vesora as vs

fig = vs.subplots(2, 2, title="Measurements", width=1100, height=800)
hist = fig.panel(0, 0).hist([1, 2, 2, 3, 3, 3, 4, 8], bins=8)
bars = fig.panel(0, 1)
bars.bar(["A", "B", "C"], [4, 7, 6], label="Before")
bars.bar(["A", "C"], [5, 8], label="After")
fig.panel(1, 0).boxplot([[1, 2, 3, 4, 12], [2, 3, 3, 4], []],
                        labels=["Batch A", "Batch B", "Empty"])
fig.panel(1, 1).plot(["Small", "Medium", "Large"], [4, 7, 6])
hist.set_options(density=True)
fig.bookmark("Overview")
fig.save_html("statistics.html")
```

In JavaScript, the methods take an options object and use camelCase: `setOptions`, `setBarMode`, `setCategories`, `barWidth` and `boxWidth`. `Figure` and `Panel` methods return one mutable `Layer`, including composite boxplots. Top-level functions preserve each language's existing return convention. See the [statistical API](../api.md#analyze-distributions-and-categories) for updates, baselines and normalization.

## Included in v0.4

- Histograms with integer or explicit-edge bins, range filtering, density normalization and cumulative counts/probabilities. Bins do not change during pan or zoom.
- Vertical/horizontal bars with grouped, stacked and overlay modes. Missing categories retain group slots; hidden series retain slots but do not contribute to stacks. Positive and negative stacks accumulate separately within each panel.
- Boxplots with exact linear-interpolated quartiles, configurable IQR fences, optional outlier marks, ragged/empty groups and deterministic singleton behavior.
- Append-only categorical x/y coordinates for line/scatter, and category positions for bars/boxes. Shared axes use a shared map. Bookmarks restore views without resetting category identity.
- Atomic data/options validation, typed bar/bin/group selection, statistical hover and inspector summaries, whole-layout PNG and self-contained HTML with raw source buffers.
- Worker/cooperative-fallback preparation, versioned multi-source caches, stale-result rejection and explicit geometry-budget errors rather than silent statistical sampling.
- Six matched Python/JavaScript examples in the [statistics gallery](../../examples/web/statistics.html): histogram, density/CDF, grouped bars, signed stacked barh, boxplots and categorical line/scatter. The three galleries now contain 25 examples per language.

New statistical layers use linear 2D axes. Existing numerical plots retain log support. Violin/KDE, date axes, DataFrame integration, error bars/bands, SVG/PDF, streaming, linked brushing and new renderers remain outside this release.

## Compatibility and interpretation

New features use scene protocol `3`; the reader accepts `1`, `2` and `3`. Numeric legacy scenes retain their original protocol unless a newer feature is used. Adding annotations to a v3 scene cannot downgrade it. The HTML envelope remains `formatVersion: 1` and embeds its matching runtime.

Selections identify **bar rows, histogram bins or box groups**, not raw sample indices, and retain the existing 10,000-index truncation contract. Inspector `visible` counts for histogram/boxplot refer to source samples in intersecting whole bins/groups, not a raw viewport filter. Non-finite values and histogram range exclusions are reported separately.

For unusually small boxplot `whis` values with no observation between a quartile and its fence, the whisker falls back to that quartile; the API documents this empty-fence convention. Numerical geometry that cannot be represented and frames exceeding the vertex budget fail explicitly.

## Local artifacts and verification

Build and validate the release locally:

```bash
npm run check
python -m pytest tests/python
npm run test:parity
npm run test:examples
npm run test:browser
npm run package:release
npm run test:packages
```

`dist/release-v0.4.0` contains:

- `vesora-0.4.0-py3-none-any.whl`
- `vesora-core-0.4.0.tgz`
- `vesora-discovery-demo.html`
- `vesora-comparison-demo.html`
- `vesora-statistics-demo.html`
- `SHA256SUMS.txt`

The clean-consumer check installs the wheel without dependencies and the tarball in an offline npm project outside the checkout. It checks installed TypeScript declarations and opens Python/JavaScript HTML with networking disabled, then exercises bookmarks and PNG export. Real Qt and Jupyter tests are separate opt-in checks; a skipped test is not evidence of working host integration. See [development](../development.md) for commands and host requirements.
