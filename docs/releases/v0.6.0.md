# Vesora v0.6.0 — React SaaS integration and shared presentation

Build line, bar and scatter cards in a React/TypeScript application, apply product themes, format dates/currency/percentages and update API data. The framework-independent scientific engine and Python facade remain available.

**Local developer preview, MIT licensed.** Packages must be built from this checkout or installed from the generated release archives. They have not been published to npm or PyPI as part of this work. Registry publication requires authenticated credentials and is separate from building packages. WebGL2 remains required; Python desktop display uses QtWebEngine and NumPy remains optional.

## React application API

`@vesora/react` provides a declarative `VesoraChart` with typed row keys and series. It owns figure creation, updates and cleanup; exposes theme/axis settings, tooltips, legends, application callbacks and loading/empty/error rendering; and provides ref methods for PNG, interactive HTML and view reset.

```tsx
import { VesoraChart } from '@vesora/react';

const rows = [
  { timestamp: Date.UTC(2026, 9, 1), revenue: 4200 },
  { timestamp: Date.UTC(2026, 9, 2), revenue: 5100 },
];

export function RevenueCard() {
  return <VesoraChart type="line" data={rows} xKey="timestamp"
    series={[{ key: 'revenue', label: 'Revenue' }]}
    theme="dark" height={320}
    xAxis={{ type: 'time', format: 'date', timeZone: 'UTC' }}
    yAxis={{ format: 'currency', currency: 'USD' }} />;
}
```

Use stable series keys and supply new props for data refresh. The [SaaS starter](../../examples/react-saas/) demonstrates simulated API refresh, date filtering, theme switching and a detail view. See the [React API](../../packages/react/README.md) for the supported interface. Basic line/bar/scatter support does not establish that Vesora replaces a broader SaaS chart library.

## Shared themes and axis formatting

JavaScript uses `figure({theme: 'dark'})`, `setTheme(...)`, `setAxisFormat('x' | 'y', format)` and `setView({xScale: 'time'})`. Python exposes the matching options:

```python
import vesora as vs

fig = vs.subplots(1, 2, sharex=True, theme="dark", title="Daily measurements")
days = [0, 86_400_000]
fig.panel(0, 0).plot(days, [4200, 5100], label="Revenue")
fig.panel(0, 1).plot(days, [2100, 2300], label="Cost")
fig.panel(0, 1).set_axes(xscale="time")
fig.panel(0, 1).set_axis_format("x", {
    "kind": "date", "locale": "en-US", "timeZone": "UTC",
    "options": {"year": "numeric", "month": "short", "day": "numeric"},
})
fig.set_axis_format("y", {"kind": "currency", "currency": "USD"})
fig.set_theme({"background": "#ffffff", "palette": ["#3569c8", "#d36a55"]})
fig.save_html("daily-measurements.html")
```

- Themes support light/dark presets and partial token overrides. Scenes store the resolved color/font/palette tokens, isolated from caller mutation.
- Time scales use numeric epoch milliseconds on 2D x/y axes. There is no implicit Python `datetime` or string-date conversion; finite calendar coordinates and explicit domains must fit the JavaScript Date range. The same range validation applies to an explicit date format on a linear axis. Date formatting defaults to UTC when no timezone is supplied.
- Number, currency, percent and date formats are serializable declarations. Rendering uses the shared engine's `Intl` formatting; scenes do not store executable format callbacks. Locale-specific glyphs and punctuation depend on the viewer's Intl implementation.
- Shared axes propagate scale, limits and format while panel labels remain independent. `set_axis_format(axis, None)` / `setAxisFormat(axis, null)` restores automatic formatting.
- Histograms and boxplots retain linear-axis requirements. Bars allow time positions with a linear value axis; explicit bar width is in the position axis's units, including milliseconds.

Explicit themes, time scales or axis formats promote a scene to protocol 5. Graphs using only earlier features retain protocol 1, 2, 3 or 4. The v0.6 runtime continues reading these older scenes. Export embeds a matching runtime and source data; React callbacks, live API connections and Python callbacks are not serialized. Linked v0.5 selection retains its original scope and bounded event-index preview.

## Build and assess

```bash
npm ci
npm run build
npm run demo:react
python -m pytest tests/python
npm run test:parity
npm run package:release
```

Install the matching generated `vesora-core-0.6.0.tgz` and `vesora-react-0.6.0.tgz` archives into a React project. React 18.3/19 is a peer dependency. `npm run publish:packages` is a separate registry operation requiring npm login; packaging does not publish anything.

The [five-developer pilot](../pilot-v0.6.md) defines the agreed adoption criteria. It has not been executed. Bundle/performance comparisons and adoption advantages must be supported by measured results rather than inferred from architecture or feature availability.
