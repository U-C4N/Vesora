# v0.9 historical validation evidence

These records belong to RC1 or earlier development builds. They preserve the evidence previously listed in the release checklist; they do not establish RC2 results. Use the [current release checklist](v0.9.0.md) for the candidate and outstanding work. New runtime or archive bytes require their own evidence.

## Tagged RC1 and viewer development checks

RC1 retained six passed gates: correctness, browser, packages, React consumers, Qt and Jupyter. **Performance failed**; soak, accessibility and beta pilot were not completed. No public release is claimed. The [measured record](../benchmarks/v0.9.0.md) preserves the failed timing values and environment.

The local [release-gates.json](../../dist/release-v0.9.0-rc.1/release-gates.json) and [evidence directory](../../dist/release-v0.9.0-rc.1/evidence/) belong to the immutable RC1 archive. These ignored artifacts must be retained with that archive; a source-only checkout may not contain them.

The final RC1 archives were built from clean commit `12bf3042beca41a94694e7394d252c21adac361b` and local tag `v0.9.0-rc.1`; manifest SHA-256 `54275cc2ecb0b1adf64556408850563a16d87f3ba6ba8c1fa7d57770243c68eb`. Their evidence directory retains 230 core tests, 40 React tests, 166 Chromium cases, six Firefox/WebKit cases, exact installed React 18.3.1/19.3.0 consumers, 13 Qt cases and 20 real Jupyter kernel cells. Installed Python 3.10.21, 3.11.15 and 3.14.6 each passed 380 tests with 15 opt-in host tests skipped; the required Qt/Jupyter checks ran separately. Qt presentation p95 was 195.30 ms and Jupyter p95 247.71 ms, both within 300 ms. This record belongs to RC1; it is neither a publication nor evidence that its failed performance gate passed.

On 2026-10-15 the viewer/adapter work was built and typechecked locally. A focused React/viewer/scientific-3D run passed **59 tests across six files**; the subsequently extended viewer unit suite passed **9 tests**. The focused viewer Chromium suite completed cleanly with **5 tests passed**, including narrow mixed-panel layout, keyboard/reduced-motion checks, and selected scientific observation export/offline reopening. A further **24-case matrix** passed at 360/768/1440 widths, DPR 1/2, both themes and both reduced-motion settings. Native Chromium **200% browser zoom passed** through its automatic zoom API, separately from viewport reflow emulation. See the [viewer QA scope and evidence](../qa/v0.9.0-viewer.md). These are development checks, not the complete release acceptance record; real screen-reader operation remains pending.
