# Vesora v0.5.0 — Linked observation inspection

Select unusual observations, inspect the same rows in another variable and compare their count distribution with the full dataset. Python and JavaScript use the same exact cohort computation; offline HTML preserves the completed selection.

**Local developer preview.** Build from this checkout. Packaging does not publish to GitHub, PyPI or npm. WebGL2 remains required, PySide6/aiohttp remain the base Python dependencies, and NumPy remains optional.

## Inspect one aligned dataset

```python
import vesora as vs

fig = vs.subplots(1, 3, width=1200, title="Linked observations")
x, residual, feature = [0, 1, 2, 3], [0.1, 0.2, 3, 0.1], [0.1, 0.2, 0.9, 0.3]
a = fig.panel(0, 0).scatter(x, residual)
b = fig.panel(0, 1).scatter(feature, residual)
h = fig.panel(0, 2).hist(residual, bins=[0, 1, 2, 4])
link = fig.link_selection(scatter=[a, b], histogram=h)
fig.show()
fig.save_html("linked.html")
```

JavaScript uses `fig.linkSelection({scatter: [a, b], histogram: h})`. Both handles provide `clear()` and `remove()`. Run the complete [model-error gallery](../../examples/web/linked.html), or read [the API](../api.md#follow-observations-across-views).

## Included

- One group of exactly two numeric scatter layers and one count histogram, in three distinct 2D panels. Equal source row positions identify observations.
- Rectangle selection from either scatter; complete original-source membership, including dense views and more than 10,000 selected rows. Event indices are a bounded preview.
- Linked scatter highlights and selected/full count histograms with identical fixed bin edges. Histogram omissions/range exclusions are distinguished from selected row count.
- Clear selection, selected count/percentage, separate empty and cleared states, view/bookmark preservation and completed-selection offline HTML/PNG export.
- Protocol 4 link semantics and legacy protocol 1/2/3 support; source/options mutation is rejected until unlinking, and member buffers are isolated from caller TypedArray aliases.
- One deterministic 200,000-row Python/JavaScript gallery example; four standalone release demos; linked selection benchmark and a five-person pilot protocol.

## Scope and limits

Explicitly align arrays before linking. Vesora does not infer dataset identity or join rows. Member data and histogram options remain fixed while linked; remove the link, update arrays, then re-link. Other layers and style/view changes remain available.

Linked histograms support counts only: density/CDF, weights and histogram-originated cohort selection are outside this release. Linked lines, categorical scatter, lasso, multiple links, set operations, streaming, uncertainty bands and SVG/PDF remain future work. Existing independent histogram normalization APIs remain available.

Exact selection still scans in-memory source data. Worker copies, derived geometry and GPU buffers add memory beyond the bounded result cache. A million-row benchmark is a measured workload, not a universal latency/FPS promise or a competitor speedup claim.
