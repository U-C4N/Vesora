# Vesora v0.1.0 — İlk geliştirme ön sürümü

Python ve JavaScript/TypeScript artık aynı TypeScript görselleştirme motoruyla 2D bilimsel grafikler ve temel 3D sahneler oluşturabiliyor. Bu ilk ön sürümde API henüz kararlı değildir.

## Bu sürümde

- WebGL2 ile line, scatter, heatmap, surface ve 3D scatter; eksenler, legend ve colorbar.
- Pan, zoom, 2D seçim, 3D kamera ve mevcut layer üzerinde veri/stil güncellemeleri.
- Yoğun nokta verisinde count aggregation, çizgilerde extrema ve veri boşluklarını koruyan azaltma; incelenebilir temsil bilgisi.
- Python listeleri ve standart sayısal buffer'larla kullanım; NumPy isteğe bağlıdır.
- Paketlenmiş ortak motorla Qt masaüstü penceresi, notebook adaptörü ve PNG çıktısı.
- NumPy gerektirmeyen Python kodlarıyla 16 etkileşimli galeri örneği. AI karşılaştırmalarındaki veriler temsilidir.

## Kurulum

Release'in Assets bölümünden ilgili dosyayı indirin. Python 3.10+ için:

```bash
python -m pip install ./vesora-0.1.0-py3-none-any.whl
```

Python wheel motoru içerir; son kullanıcı için Node.js gerekmez. `aiohttp` ve `PySide6` otomatik kurulur. Notebook için aynı wheel'i `"./vesora-0.1.0-py3-none-any.whl[notebook]"` şeklinde kurabilirsiniz.

JavaScript/TypeScript frontend projenizde:

```bash
npm install ./vesora-core-0.1.0.tgz
```

Paket adı `@vesora/core` olur. Bir bundler üzerinden import edin veya paket içindeki `dist/index.js` ve `dist/worker.js` dosyalarını aynı dizinde HTTP üzerinden sunun. TypeScript bildirimleri pakete dahildir.

Bu release GitHub üzerinden dağıtılır; npm veya PyPI yayını içermez. Kullanım örnekleri için [README](https://github.com/U-C4N/Vesora/blob/v0.1.0/README.md) ve [API belgesine](https://github.com/U-C4N/Vesora/blob/v0.1.0/docs/api.md) bakın. `SHA256SUMS.txt` indirilebilir paketlerin SHA-256 özetlerini içerir.

## Doğrulama ve sınırlar

TypeScript tür kontrolü, 31 birim testi, 105 Python testi (5 gerçek Qt masaüstü testi dahil), 10 tarayıcı testi, Python/JS sahne eşdeğerliği ve 32 galeri kod örneği yerelde doğrulandı. Tarayıcı testleri yazılımsal WebGL kullanır; bu sonuçlar GPU performans ölçümü değildir.

WebGL2 ve masaüstü için çalışan bir grafik ortamı gerekir. Veri sağlayıcıları bu sürümde bellek içidir; 100 milyon kayıt için genel bir performans garantisi yoktur. WebGPU, SVG/PDF export, volume rendering, indeksli disk/streaming verisi ve vector_field henüz bulunmaz.
