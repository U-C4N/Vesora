# Vesora v0.1.0 — Initial development prerelease

Python and JavaScript/TypeScript can create 2D scientific plots and basic 3D scenes through the same TypeScript visualization engine. The API is not yet stable in this first prerelease.

## Included in this release

- WebGL2 line, scatter, heatmap, surface, and 3D scatter rendering, with axes, legends, and colorbars.
- Pan, zoom, 2D selection, a 3D camera, and data/style updates on existing layers.
- Count aggregation for dense point data, line reduction that preserves extrema and gaps, and inspectable representation metadata.
- Python lists and standard numeric buffers; NumPy is optional.
- A Qt desktop window, notebook adapter, and PNG export using the bundled shared engine.
- Sixteen interactive gallery examples with NumPy-free Python code. AI comparison data is synthetic.

## Installation

Download the appropriate file from the release's Assets section. For Python 3.10+:

```bash
python -m pip install ./vesora-0.1.0-py3-none-any.whl
```

The Python wheel includes the engine; end users do not need Node.js. `aiohttp` and `PySide6` are installed automatically. For notebook support, install the same wheel as `"./vesora-0.1.0-py3-none-any.whl[notebook]"`.

In a JavaScript/TypeScript frontend project:

```bash
npm install ./vesora-core-0.1.0.tgz
```

The installed package is named `@vesora/core`. Import it through a bundler, or serve the package's `dist/index.js` and `dist/worker.js` files together in the same directory over HTTP. TypeScript declarations are included.

This release is distributed through GitHub; it does not publish packages to npm or PyPI. For current English usage examples, see the [README](https://github.com/U-C4N/Vesora/blob/main/README.md) and [API guide](https://github.com/U-C4N/Vesora/blob/main/docs/api.md). `SHA256SUMS.txt` contains the SHA-256 hashes of the downloadable packages.

## Verification and limits

At release time, TypeScript type checking, 31 unit tests, 105 Python tests (including five real Qt desktop tests), 10 browser tests, Python/JavaScript scene parity, and 32 gallery code examples were verified locally. Browser tests use software WebGL; these results are not GPU performance measurements.

WebGL2 is required, and the desktop host needs a working graphics environment. Data providers are in-memory in this version; there is no general performance guarantee for 100 million records. WebGPU, SVG/PDF export, volume rendering, indexed disk/streaming data, and `vector_field` are not implemented yet.
