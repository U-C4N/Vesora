# Vesora v0.8.0 — bounded telemetry and runtime recovery

v0.8 adds bounded numeric line/scatter streaming to the shared Python, JavaScript and React engine. It retains the existing plotting, presentation and offline scene contracts, including protocols 1–6. This is a local developer preview under the MIT license; generating archives does not publish to npm, PyPI or GitHub.

## What changed

- **Bounded append operations:** explicit per-layer capacity, owned immutable chunks, atomic channel validation, multi-series JavaScript/React transactions, and retained/evicted counters. Reset starts a new epoch; sample sequences remain stable through eviction.
- **Progress during continuous updates:** one active frame and the latest requested state, revision-fenced readiness, bounded append waits, independent selection planning and coalesced/indexed hover. Presentation-only React updates preserve source versions.
- **Incremental host transfers:** worker chunk recipes and acknowledged binary desktop/notebook deltas, per-view recovery snapshots, an 8 MiB pending-delta limit and a 1,024-update record limit. Closed notebook widgets can be redisplayed with a fresh connection.
- **Recovery and diagnostics:** worker startup/progress timeouts, cooperative fallback, WebGL restoration on the same figure, abortable/timed readiness, optional source/cache/geometry limits and component-level memory counters.
- **Stable exports:** PNG captures the invocation-time view and retained data while producers continue. Offline HTML contains a static retained snapshot with no live connection or streaming metadata.
- **Usable live inspection:** the web and React demos pause incoming samples when a pan, zoom or sample inspection begins, preventing the inspected window from being evicted. Resume returns to the live view. The web demo preserves its figure during cached browser back/forward navigation and displays initialization failures above the chart.
- **Release verification:** exact archive checksums, provenance manifest, seven real offline demos with PNG checks, and expanded CI definitions for Python versions, React consumers, alternate browsers and installed-wheel hosts.

The [streaming guide](../streaming.md) documents supported channels, failures, identity, backpressure and examples. Run the matching three-curve examples in [JavaScript](../../examples/web/streaming.html), [Python](../../examples/python_streaming.py) and [React](../../examples/react-saas/README.md).

## Compatibility and limits

Existing `setData`/`set_data`, static scenes, layers and exports remain available. Streaming is opt-in and does not add protocol 7. Python still requires `aiohttp` and `PySide6`; NumPy remains optional. WebGL2 remains required. No renderer or dependency replacement is part of this release.

Only numeric 2D lines and scatters can stream. Bands, categories, statistical layers, 3D and dynamic linked-selection membership remain outside the streaming API. The application must persist full history if it needs evicted rows. Streaming capacity bounds canonical retained data; frozen exports, frame copies, worker storage, geometry, caches and user-held references consume additional memory. Reported GPU bytes are estimates, not driver allocation measurements.

Sorted line queries use cached chunk summaries and binary x-range narrowing. General scatter queries can still scan the retained data. See [the measurement report](../benchmarks/v0.8.0.md) for observed results; the feature list alone establishes no throughput or frame-rate guarantee.

## Build and inspect the release candidate

```bash
npm ci
npm run check
python -m pip install "setuptools>=77" wheel
npm run package:release
npm run test:packages
npm run test:release
```

`dist/release-v0.8.0/` contains three archives, seven standalone HTML demos, `release-manifest.json` and `SHA256SUMS.txt`. The checksum file covers all 11 distributable entries. The manifest records runtime SHA-256 values, package/runtime versions, source commit and dirty-tree status. These identify the local build; a published release should be rebuilt from its final tagged commit.
