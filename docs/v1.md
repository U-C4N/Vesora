# Vesora 1.1.0 analysis guide

Version 1 extends the existing shared engine with ten analysis families. 1.1.0 keeps these families; viewer and interaction changes are in the [1.1.0 notes](releases/v1.1.0.md). JavaScript `Figure` and `Panel` use the same methods; Python uses snake_case. React analysis figures use `VesoraViewer`, preserving application ownership. No chart runtime dependency is introduced.

The maintained [analysis contracts](../skills/vesora/references/analysis.md) describe matrix orientation, supplied bounds and projection requirements. Executable examples exercise all ten families in [JavaScript](../skills/vesora/scripts/example_js.mjs), [Python](../skills/vesora/scripts/example_python.py) and [React](../skills/vesora/scripts/example_react.tsx).

## Public API

| JavaScript | Python | Meaning |
| --- | --- | --- |
| `ecdf`, `ccdf` | `ecdf`, `ccdf` | Unbinned empirical distribution and complementary tail |
| `spectrogram` | `spectrogram` | Time × frequency matrix; bounded `appendRows` / `append_rows` |
| `eventTimeline` | `event_timeline` | Instants and intervals in lanes |
| `errorbar` | `errorbar` | Explicit asymmetric x/y coordinate bounds |
| `contour`, `contourf` | `contour`, `contourf` | Scalar-grid isolines and filled regions |
| `quiver` | `quiver` | Vector origins and components |
| `parallelCoordinates` | `parallel_coordinates` | Row-aligned named columns and configurable axes |
| `paretoFront` | `pareto_front` | Two explicit min/max objectives and nondominated candidates |
| `phasePortrait`, `hysteresis` | `phase_portrait`, `hysteresis` | Ordered trajectories, optional time/sequence and direction |
| `ternary` | `ternary` | Three nonnegative components with a declared total |

Use installed TypeScript declarations for complete optional properties and types. See the skill host guides for Python option spelling and React lifecycle. Malformed input must not partially update a chart.

For percentile and threshold inspection, use the pure `queryECDF(samples, {probability: 0.99, threshold: 30})` helper (`vs.query_ecdf(samples, probability=0.99, threshold=30)` in Python). Quantiles use nearest rank; threshold counts distinguish values at or below the threshold from strictly greater values. Nonfinite values are counted as omitted, not replaced. Source membership previews are bounded while full counts remain exact.

`createRunComparison` / `create_run_comparison` returns matched values, source indices, differences/residuals and ratios. A missing sample, nonfinite result or zero reference produces a null ratio. Exact alignment is the default; nearest/linear alignment and event offsets are explicit, and values are never silently converted between units.

## Examples

```js
const fig = figure({title: 'Measured response'});
fig.errorbar([0, 1, 2], [2, 3, 2], {
  yLower: [1.5, 2.8, 1.7], yUpper: [2.4, 3.5, 2.3],
});
```

```python
fig = vs.figure(title="Retained supplied spectrum")
spectrum = fig.spectrogram(
    [0, 1], [10, 20, 30], [[1, 2, 1], [2, 5, 2]], max_rows=64
)
spectrum.append_rows([2], [[1, 3, 4]])
fig.save_html("spectrum.html", observation=True)
```

Spectrogram values are precomputed. Vesora does not infer sampling rate, FFT window, power/amplitude convention or uncertainty estimates. Ternary/quiver normalization changes visual encoding and is an explicit choice.

Use a fixed `colorDomain` when comparing spectra over time or relying on the dirty-row GPU update path. With automatic color limits, a changed domain requires correct renormalization of the retained texture; constant partial-upload work is not promised in that case. Normalization occurs in Float64 on the CPU before the display representation to preserve large/small supplied scalar values.

## Compatibility and boundaries

The [browser gallery](../examples/web/v1.html) and React `?demo=v1` route share three workflow factories: a retained waveform/spectrum/event workspace, an exact event-offset run comparison with delta panel, and a stable-ID scatter/ECDF/parallel/Pareto cohort with a paginated application table. Theme, dataset, freeze/resume, retained append, time-window and export controls use public APIs. See the [workflow contracts](../skills/vesora/references/workflows.md).

- Scene protocol **9** carries analysis data/options. Protocols 1–8 remain readable. Older runtimes reject unsupported newer scenes rather than discard layers.
- Existing charts retain earlier protocols when new fields are unnecessary. Observation metadata remains paired with matching source values.
- Parallel-coordinate and ternary projections occupy their own initially empty 2D panels; do not mix them with Cartesian layers or shared axes.
- Source picking/export preserves original identity. Aggregate selections remain aggregates. Existing linked selection keeps its member restrictions.
- Generic line/scatter streaming and spectrogram appended rows are separate contracts; not every analysis family gains generic streaming.
- Offline HTML holds values and the matching runtime. It does not resume producers, serialize callbacks, retain evicted history or certify scientific correctness.

`npm run verify:next` runs bounded automatic verification and records actual passed/failed stages. It neither publishes nor changes old RC acceptance records. Read the [verification contract](verification-v1.md).
